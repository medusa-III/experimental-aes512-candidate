# Security Policy / Cryptanalysis Reports

This experimental cipher candidate intentionally invites independent cryptanalysis.

If you find any of the following, please report it with enough detail to reproduce:

- full-round key recovery
- full-round distinguishers
- reduced-round distinguishers
- differential or linear trails/hulls
- integral properties
- impossible differentials
- invariant subspaces
- related-key weaknesses
- weak-key classes
- meet-in-the-middle or biclique shortcuts
- algebraic reductions
- implementation bugs
- side-channel weaknesses

A useful report should include:

1. exact version/hash tested
2. number of rounds affected
3. attack model
4. data complexity
5. time complexity
6. memory complexity
7. success probability
8. reproducible code or equations when possible

The project currently makes no production-security claim.
